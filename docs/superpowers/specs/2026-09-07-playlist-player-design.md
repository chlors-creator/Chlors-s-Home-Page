# 歌单与播放器设计

## 目标

为现有 Astro 静态个人网站增加“04 歌单”入口、八个歌单分类和可实际播放仓库内 MP3 的播放器页面。用户只需把 MP3 文件放入对应目录；构建过程自动读取歌曲名、歌手、时长和内嵌封面。现有侧边栏、主题背景、客户端换页方式保持一致。

## 导航与路由

- 侧边栏在“03 专题”后增加“04 歌单”。
- 原“日志、友链、关于”顺延为“05、06、07”。
- 歌单索引路由为 `/playlists/`，视觉结构复用专题页的卡片网格。
- 播放器路由为 `/playlists/[slug]/`，保留固定侧边栏和当前主题背景。
- 播放器正文左上方提供返回歌单索引的箭头。

八个固定分类：

| 名称 | slug | MP3 目录 |
| --- | --- | --- |
| 电音 | electronic | `public/music/electronic/` |
| 日系流行 | japanese-pop | `public/music/japanese-pop/` |
| 华语流行 | chinese-pop | `public/music/chinese-pop/` |
| 后摇&后朋 | post-rock-punk | `public/music/post-rock-punk/` |
| Phonk | phonk | `public/music/phonk/` |
| 数摇 | math-rock | `public/music/math-rock/` |
| 中西部emo | midwest-emo | `public/music/midwest-emo/` |
| Piano | piano | `public/music/piano/` |

## 构建时音乐清单

- `prebuild` 和本地开发启动前执行音乐扫描脚本。
- 扫描脚本只读取上述八个目录中的 `.mp3` 文件。
- 从 ID3 标签提取标题、歌手和内嵌封面，从 MPEG 帧信息读取时长。
- 标题缺失时回退到不含扩展名的文件名；歌手缺失时显示“未知艺术家”；封面缺失时使用站内统一默认封面。
- 内嵌封面导出到生成目录，播放器页面不在浏览器中重复解析 MP3。
- 生成的清单包含分类、音频 URL、封面 URL、标题、歌手和秒级时长。
- 损坏或无法解析的 MP3 被跳过，并在构建输出中给出文件名明确的警告；其他歌曲继续生成。
- 歌曲默认按文件名自然排序，以便用户通过文件名前缀控制顺序。

生成清单和封面属于构建产物，不要求用户手工编辑。空目录保留 `.gitkeep`，以便仓库保存八个分类结构。

## 播放器界面

播放器正文沿用当前主题的背景与文字颜色。中央上方放置柔和灰色、圆角矩形播放框。

播放框从上至下包括：

1. 当前歌曲名；没有歌曲时显示“暂无歌曲”。
2. 控制行：左侧为播放模式切换，中间依次为上一首、红底白字播放/暂停键、下一首，右侧为音量滑杆。
3. 播放进度条：未播放部分为灰色，已播放部分为红色；悬停和键盘聚焦时向上增厚；白色圆点可拖动定位。
4. 当前时间与总时长，便于精确判断进度。

播放模式按以下顺序循环切换：列表循环、随机、顺序播放、单曲循环。模式按钮同时显示当前模式文字，避免仅靠图标产生歧义。

播放框下方是歌曲列表。每行显示专辑封面、歌曲名、较小字号歌手名，以及最右侧的时长。点击歌曲行立即加载并播放；当前歌曲行显示红色强调状态。空歌单显示“暂无歌曲，请将 MP3 放入对应目录”。

## 播放内核与行为

- 使用 MIT 许可的 AmplitudeJS 作为播放内核，自定义本站的 HTML、CSS 和控制界面，不采用其示例皮肤。
- AmplitudeJS 负责真实音频的加载、播放/暂停、上一首、下一首、音量、进度定位和歌曲切换。
- 播放模式由本站状态层映射到 AmplitudeJS：列表循环在末曲结束后回到首曲；随机选择不同歌曲；顺序播放在末曲结束后停止；单曲循环重复当前歌曲。
- 拖动进度条时即时更新显示，释放后设置 `currentTime`。
- 音量和播放模式保存在 `localStorage`，下次访问恢复；当前歌曲和播放进度不跨页面恢复。
- 离开播放器路由时调用 AmplitudeJS 停止播放并清理当前歌单状态，避免切换页面后继续发声。
- 尊重键盘操作、ARIA 标签和 `prefers-reduced-motion`。

## 响应式设计

- 桌面端保持侧边栏固定，播放框居中，歌曲列表在其下方展开。
- 移动端沿用当前网站的顶部侧边栏布局；控制行允许分区换行，但播放/暂停键始终居中且保持最高视觉优先级。
- 歌曲标题和歌手过长时单行省略，时长列保持可见。
- 进度条提供足够的触控高度，视觉轨道仍保持细线风格。

## 现有界面约束

- 主题选择窗口中，所有未选中卡片和色块无黑色或白色边框；只有选中主题显示橙色边框。
- 主内容及左上圆角遮罩起点使用 `299px`，与侧边栏右边线视觉对齐。
- 歌单页面沿用现有页面右侧切入动画，侧边栏和背景不参与滑入。

## 文件组织

- `src/data/playlists.ts`：八个分类定义及生成清单类型。
- `scripts/build-music-library.mjs`：扫描 MP3、读取元数据、导出封面、生成清单。
- `src/generated/music-library.json`：自动生成的音乐清单。
- `src/pages/playlists.astro`：歌单索引。
- `src/pages/playlists/[slug].astro`：播放器路由。
- `src/components/MusicPlayer.astro`：播放器结构。
- `public/music-player.js`：AmplitudeJS 初始化、播放器交互和播放模式状态。
- `src/styles/music-player.css`：播放器及歌单专用样式。
- `public/music/<slug>/`：用户放置 MP3 的八个目录。
- `public/generated/music-covers/`：自动导出的封面缓存。

## 验证标准

- 空歌单情况下，八个索引卡片和八个播放器页面均能成功构建。
- 放入带完整 ID3 的 MP3 后，页面正确显示标题、歌手、封面和时长，并能播放、暂停、切歌、调音量及拖动进度。
- AmplitudeJS 只作为播放内核加载，不引入默认播放器皮肤或改变本站视觉系统。
- 缺少部分 ID3 字段的 MP3 使用规定的回退值。
- 四种播放模式在单曲、多曲和列表末尾均符合定义。
- 普通主题、黑色主题和图片主题下内容清晰，侧边栏与背景保持不动。
- 桌面和移动视口无横向溢出、遮挡或不可操作控件。
- 页面切换、主题按钮、当前页导航拦截和状态上报功能无回归。
